דרך לעבודה — מחשבון נסיעות חכם
גרסה אוטומטית — 07.10.2026

איך האתר עובד:
- המשתמש מזין מוצא ויעד בלבד.
- האתר מחשב את המרחק האווירי ובוחר את מדרגת המחיר.
- חופשי חודשי מוצג כ-139 ₪ באזור 1, או כחופשי ארצי לפי המסלול.
- אם אין נתוני עדכון זמינים, האתר ממשיך לעבוד עם התעריפים האחרונים שנבדקו.

עדכון תעריפים אוטומטי:
- data/fares.json הוא קובץ התעריפים שהאתר קורא בזמן אמת.
- scripts/update-fares.mjs בודק מקורות רשמיים של משרד התחבורה.
- נסיעות בודדות נבדקות מול קובצי ה-GTFS הרשמיים.
- מחירי חופשי חודשי נבדקים מול עמוד התעריפים הרשמי bus.gov.il/FaresDistance.
- .github/workflows/update-fares.yml מריץ את הבדיקה בכל יום.
- אם המחיר הרשמי השתנה, GitHub מעדכן אוטומטית את data/fares.json ומבצע commit.
- כאשר Netlify מחובר לריפו ב-GitHub, כל commit כזה גורם לפריסה אוטומטית של האתר.

חשוב:
העלאה ידנית ב-Drag & Drop ל-Netlify ממשיכה לעבוד, אבל עדכון תעריפים אוטומטי דורש לחבר פעם אחת את האתר לריפו ב-GitHub. אחרי החיבור אין צורך להעלות ZIP בכל שינוי מחיר.

פריסה ראשונה ב-GitHub + Netlify:
1. פותחים ריפו חדש ב-GitHub.
2. מעלים אליו את תוכן התיקייה travel_calc (כולל התיקייה .github).
3. ב-Netlify מחברים את האתר הקיים לריפו.
4. Publish directory: .
5. אין Build command.
6. אחרי הפריסה, אפשר להריץ ידנית את Action בשם "Update official transit fares" כדי לבדוק שהכול עובד.

גיבוי:
גם אם מקור רשמי לא זמין זמנית, העדכון לא מוחק מחירים קיימים והאתר ממשיך עם התעריפים האחרונים התקינים.
